# Hinglish YouTube Autopilot (Android-configurable)

Creates **7 vertical Shorts + 1 horizontal long-form video per weekly run**.
The scripts are generated by Gemini; voice is generated by Microsoft Edge TTS;
visuals are original procedural title-card scenes rendered with FFmpeg.
The workflow runs in GitHub Actions, so your Android phone does not need to stay on.

## Important reality checks

- This is a best-effort zero-subscription setup, not a guaranteed forever-free commercial service.
- Gemini's free API tier has model-specific rate limits and can change. Check Google AI Studio before relying on it.
- Edge TTS uses Microsoft's online speech service through an unofficial client library. Availability, voice behaviour and service terms can change. It is not an offline voice engine.
- The visuals are generated graphic scenes, not photorealistic AI video. The videos may look like narrated animated story cards. This avoids paid image/video-generation services.
- YouTube API OAuth and channel eligibility are required. Scheduling uses private uploads with `publishAt`; account/API project restrictions can affect publishing.
- Automated scripts can make factual errors. The prompt asks for careful wording, but there is no independent fact-checker. Review the first batch before enabling unattended publication.
- Do not mass-publish repetitive, low-value videos. Add original research, narrative and editorial value; YouTube monetization policies apply.
- A public GitHub repository exposes its source code. Never commit API keys, refresh tokens, OAuth client secrets or personal data.

## 1. Create the repository on Android

1. Open https://github.com/new in Chrome.
2. Name it `youtube-autopilot-hinglish`.
3. Set visibility to **Public** (GitHub-hosted standard runners are free for public repositories; public source is visible to everyone).
4. Create the repository.
5. Upload all files from this ZIP, preserving the `.github/workflows/weekly.yml` path. GitHub mobile web can upload files; if folder creation is awkward, create the folders first using **Add file → Create new file** and type the full path.

## 2. Create a Gemini API key

1. Open https://aistudio.google.com/app/apikey.
2. Create an API key in a project eligible for the free tier.
3. In the GitHub repository open **Settings → Secrets and variables → Actions → New repository secret**.
4. Name it `GEMINI_API_KEY`; paste the key as its value.
5. Optional repository variable: **Settings → Secrets and variables → Actions → Variables**; add `GEMINI_MODEL` = `gemini-2.5-flash` (or a currently available free model shown in AI Studio).

Free-tier availability and rate limits vary. Do not attach a paid billing account if you require a hard ₹0 ceiling.

## 3. Configure YouTube API access

This needs one-time Google Cloud configuration:

1. Open https://console.cloud.google.com/ and create a project.
2. Enable **YouTube Data API v3**.
3. Configure the OAuth consent screen. Add your own Google account as a test user if the app is in Testing.
4. Create an OAuth client ID of type **Desktop app**.
5. Use Google's OAuth 2.0 Playground at https://developers.google.com/oauthplayground:
   - Open the gear icon.
   - Enable **Use your own OAuth credentials** and enter your OAuth client ID and client secret.
   - In Step 1 enter scope: `https://www.googleapis.com/auth/youtube.upload`
   - Authorize with the Google account that owns the channel.
   - In Step 2 exchange the code for tokens.
   - Copy the **refresh_token**.
6. In GitHub → **Settings → Secrets and variables → Actions**, create these secrets:
   - `YOUTUBE_CLIENT_ID` = OAuth client ID
   - `YOUTUBE_CLIENT_SECRET` = OAuth client secret
   - `YOUTUBE_REFRESH_TOKEN` = refresh token

Keep the refresh token private. OAuth consent apps left in Testing can have refresh tokens expire after seven days for scopes beyond basic identity. If this happens, repeat authorization or complete the applicable publishing/verification steps. Never share your token in chat.

## 4. First test — do not publish yet

1. Open the repository's **Actions** tab.
2. Select **YouTube Autopilot**.
3. Tap **Run workflow**.
4. Keep `publish` set to **false**.
5. Run it and wait for completion. The first run can take a while because it generates 8 videos and multiple voice segments.
6. Open the completed run and download the `youtube-autopilot-output` artifact.
7. Check the narration, facts, visuals, spelling, duration and sound.

If the model ID is unavailable, change the `GEMINI_MODEL` repository variable to a free model currently available in AI Studio.

## 5. Enable scheduled uploads

Only after reviewing the test batch and confirming all secrets:

1. Open **Actions → YouTube Autopilot → Run workflow**.
2. Set `publish` to **true** for one controlled test.
3. Check your YouTube Studio account and scheduled videos.
4. The weekly cron run is configured for Sunday 03:17 UTC (08:47 India time). Scheduled publication is planned for one Short each day at 18:30 IST and the long video on Sunday at 11:00 IST, in the following week.
5. Scheduled runs set publishing to true automatically. Disable the workflow in the Actions tab if you want to stop it.

## 6. What each run does

- Generates a JSON content pack: 7 Shorts and 1 long video.
- Generates Hindi/Hinglish narration with `hi-IN-MadhurNeural`.
- Creates original starfield / mystery scene cards with Devanagari captions.
- Renders 720×1280 Shorts and 1280×720 long-form video.
- Uploads privately and sets `publishAt` for the planned dates.
- Attempts to set custom thumbnails. Thumbnail upload is best-effort.

## Settings

In `main.py`:
- Change `VOICE` via the `TTS_VOICE` environment variable if another Edge voice suits you better.
- Change the prompt to refine the channel's tone.
- Change publication times in the `datetime.combine(... time(...), IST)` lines.

## Troubleshooting

- `Missing GEMINI_API_KEY`: add the secret exactly as named.
- `429` / quota error: wait for the Gemini free-tier quota reset or choose another currently free model. Do not enable billing if ₹0 is mandatory.
- `401` / `invalid_grant`: refresh token expired/revoked; repeat OAuth authorization.
- `403` YouTube API error: check API enablement, OAuth scope, consent-screen test-user status, channel permissions and API project restrictions.
- No thumbnail: upload may have succeeded; thumbnail API can fail independently.
- Edge TTS error: service or voice may be temporarily unavailable. Rerun after checking service availability.
- GitHub scheduled job did not start: GitHub cron can be delayed; public repositories can also have scheduled workflows disabled after prolonged inactivity. Check Actions and re-enable if needed.

## Safety and editorial policy

This system does not download copyrighted videos or scrape other YouTube channels. Use only original assets or assets whose licences permit your intended use. AI-generated scripts can still contain errors. Do not present speculative paranormal explanations as established facts. Confirm claims before public release, especially science, health, safety or historical claims.
